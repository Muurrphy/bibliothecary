# Setup and configuration

## Foreground process

Run `biblio read` (or `margin serve <lesson.json> ...` without records) in a terminal on the computer. It is a local foreground service. Keep that terminal open while using the companion; close its session or press Ctrl+C to stop. This repository does not install a background service or copy the author's personal launcher.

Python 3.11+ is required. `openssl` is needed to generate local HTTPS certificates. Local audio playback uses `afplay` on macOS or `ffplay` / `mpg123`; the mobile ElevenLabs path plays audio in the browser. Local waveform checks and alignment estimation read PCM16 WAV directly. Compressed audio such as MP3 needs `afconvert` (macOS) or `ffmpeg`; without a decoder, valid provider timing remains available but is not checked against the waveform.

## Phone and Kindle

Use the printed HTTP URL on the Kindle and the HTTPS URL on the phone. The phone supplies both microphone and speaker. Tap once to unlock browser audio and grant microphone permission. Keep it awake and in the foreground. A new device must be configured separately.

Open `/speaker` on the device that should speak and listen, and `/speaker?listen=0&mute=1` on extra mouth displays. The speaking device you tapped last owns the microphone and playback; a device that lost it shows a line at the top, and tapping that line takes over again. See [known issues](known-issues.md).

## HTTPS on the phone

Margin creates a local certificate authority under `~/.margin/tls` using `openssl`. These keys and certificates stay on your computer and are not part of the repository.

For iPhone/iPad Safari:

1. Open `http://<computer-address>:8765/margin-ca.crt` and allow the profile download.
2. In Settings, install the downloaded profile.
3. Open General → About → Certificate Trust Settings and trust **Margin local CA**.
4. Open `https://<computer-address>:8765/speaker?role=primary`, allow the microphone and tap to begin.
5. Optionally use Share → Add to Home Screen.

**Microphone permission every time?** Safari remembers microphone access per address only when you tell it to: in Safari tap **aA** (or the page menu) → **Website Settings** → **Microphone** → **Allow**, or set it for all sites in Settings → Safari → Microphone (on newer iOS: Settings → Apps → Safari → Microphone). Always use the same address (the IP address and `name.local` count as two different sites). A page added to the Home Screen has no such setting, and iOS may ask once each time it is opened.

Only trust a certificate generated by your own computer. Android certificate installation varies by device and has not been validated in this project. Other e-readers' browser compatibility is not established by the Kindle demo.

## Credentials and models

Copy `.env.example` to `.env` and use your own credentials. `margin` loads `.env` from the current working directory. Never publish that file.

| Variable | Meaning |
|---|---|
| `OPENAI_API_KEY` | Chat, transcription or realtime questions. |
| `MARGIN_MODEL` | Chat model for lesson creation and text questions. |
| `MARGIN_BASE_URL` | OpenAI-compatible chat endpoint. |
| `MARGIN_REALTIME` | `1` for realtime voice; `0` for separate transcription and chat. |
| `MARGIN_REALTIME_MODEL` | Realtime model available to your account. |
| `MARGIN_STT_MODEL` | Transcription model for the classic path. |
| `ELEVENLABS_API_KEY` | ElevenLabs credential. |
| `MARGIN_ELEVEN_VOICE` | Your own ElevenLabs voice ID. |
| `MARGIN_ELEVEN_MODEL` | Optional pinned TTS model; account support is required. |
| `MARGIN_ELEVENLABS_KEYCHAIN` | Optional macOS Keychain service for the credential. |
| `MARGIN_ELEVEN_SETTINGS` | JSON object of voice settings. An explicit profile overrides Margin's built-in settings. |
| `MARGIN_ELEVEN_STRICT_SETTINGS` | `1` prevents a rejected voice profile from being silently reduced. |
| `MARGIN_NATIVE_TIMING` | `1` prefers native character timestamps. If they are unavailable, the voice continues with alignment fallback. |
| `MARGIN_ALIGN` | `local` estimates missing alignment on this computer. `elevenlabs` permits a forced-alignment audio upload. Neither is needed for the local waveform checks on native timestamps. |
| `MARGIN_VISUAL_LEAD_MS` | Optional consonant anticipation in milliseconds, bounded by neighbouring events. Defaults to `0`; it does not repair incorrect timestamps. |
| `MARGIN_SINGLE_SPEAKER` | `1` restricts capture and playback acknowledgements to one primary device. |
| `MARGIN_VOICE_CACHE_DIR` | Optional local generated-audio/text cache. Keep it out of Git. |

The `.env.example` prefers native timing, one primary device and local alignment fallback. It does not contain the author's voice settings, voice ID, credentials or local IP address. If you do not copy it, the existing code defaults remain in effect.

Voice choices: `silent` for an offline reader demo; `say` for the macOS system voice; `openai` for OpenAI TTS; `elevenlabs` for audio with character timing. The mouth/audio integration is most directly exercised by the ElevenLabs path. A generic `say` or `openai` voice does not establish full synchronized mobile-mouth support.
