# The sample book

`seneca-on-the-shortness-of-life.epub` is Seneca's *On the Shortness of Life* in Aubrey Stewart's
translation (1900). Seneca died in 65 AD and Aubrey Stewart in 1918, so the text is in the public
domain everywhere.

The text comes from the [Standard Ebooks](https://standardebooks.org/ebooks/seneca/dialogues/aubrey-stewart)
edition of Seneca's *Dialogues*, whose own work is dedicated to the public domain under CC0 1.0. This
file was made from it with `tools/make_sample_book.py` (only this dialogue, without the endnotes) and
is dedicated to the public domain in the same way.

It is shelved with `biblio book get sample`, or `/get sample` in Telegram.
