# Robot LipSync has moved into Margin

The multilingual mouth and the Kindle reading companion are now one project:

## [Margin · a reading companion across devices](https://github.com/Muurrphy/margin)

Margin lets an old Kindle show an article while a phone or iPad provides speech, questions and a digital mouth. No Kindle jailbreak is required. The mouth source, renderers, language rules, examples, tests, schemas, optional OLED firmware and benchmark tools are included in the same repository and installation.

**Ongoing development and new issues belong in [Margin](https://github.com/Muurrphy/margin).** Phone listening is still intermittent; the new project documents this as an experimental limitation.

- [English README](https://github.com/Muurrphy/margin#readme)
- [中文说明](https://github.com/Muurrphy/margin/blob/main/README.zh-CN.md)

The `robot_lipsync` Python API and `robot-lipsync` command are retained in Margin.

This repository is kept for the original source and commit history. Its last standalone source snapshot is [8b90e61](https://github.com/Muurrphy/robot-lipsync/tree/8b90e617de9af3bc5d8c33d94d40e19735abe951). The MIT license is preserved.
